# Operations Decision Toolkit

Simple browser-based tools for clearer operating decisions across margin, inventory and planning.

I built this project to learn more about practical technology through problems I already understand from operating businesses. I am not trying to replace operating judgment with a calculator. The point is to make the assumptions visible, get to the right questions faster and understand how simple tools can support better decisions.

## What is included

- **Contribution margin:** Estimates what remains from an order after the variable costs shown.
- **Inventory runway:** Estimates available inventory, days of coverage and a possible stockout date.
- **Reorder timing:** Compares inventory position with a reorder point based on demand, lead time and safety stock.

## A note about the numbers

These tools provide directional estimates. Definitions and inputs differ by business. Promotions, seasonality, subscriptions, supplier reliability, MOQs, cash requirements, shelf life and other realities still need human judgment.

## How to use it

Open `index.html` in a browser. No installation or account is required. The calculations run locally in the browser and do not save or transmit the information entered.
