Tim Fruge Operations Decision Toolkit

A practical work in progress

Small tools for decisions that usually start with a spreadsheet.

I built this to explore how simple technology can make everyday operating questions easier to see and discuss. The answers are estimates—not substitutes for the judgment behind them.

Tool 01

Contribution margin

See what remains from an order after the variable costs required to sell and fulfill it.

Different companies define contribution margin differently. This version shows every included cost so the assumptions stay visible.

Why this exists

I understand the operating questions. I’m learning more about the technology that can help answer them.

My career has put products, economics, inventory, systems and handoffs on the same desk. This project is part of learning how to turn that experience into simple, useful tools—without pretending the tool makes the decision for you.
